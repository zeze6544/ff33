# Torxth Technology

Premium website and product shop for **Torxth Technology** — a computer business in Ferntree Gully, South East Melbourne.

## Features

- Brand-led landing page with workshop photography
- Full product shop with filters, search, cart and checkout
- Services: repairs, upgrades, custom builds, software
- About & contact with map and enquiry form
- Persistent cart (localStorage), AUD pricing, pickup / delivery options

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS 4
- React Router
- Framer Motion

## Develop

```bash
cd torxth
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```
